Laporan PDF terenkripsi otomatis

Dashboard IoT web

Panel web dengan grafik real-time dan riwayat kejadian untuk sensor gas, suhu, dan kelembapan.

Radiusin: manajemen RADIUS untuk ISP

Mengelola router, pool IP yang dibagi otomatis, profil kecepatan, pelanggan, dan sesi online, plus impor CSV. Datanya langsung dipakai FreeRADIUS.

Node.js, PostgreSQL, FreeRADIUS, Docker

FieldOps: operasional lapangan ISP

Pemasangan baru, tiket gangguan, alarm jaringan, dan peta lokasi ada di satu papan kerja. Laporan Word dan PDF bisa dibuat dengan sekali klik.

Node.js, SQLite, Leaflet, docx, PDFKit

PingMap: pantau router di peta

Mengecek ping atau port router secara berkala, menampilkannya di peta, dan mengirim pesan Telegram saat ada router yang mati atau sudah hidup lagi.

Node.js, SQLite, Leaflet, Telegram Bot API

GadgetBekas: toko HP bekas

IoT Dapur AI
